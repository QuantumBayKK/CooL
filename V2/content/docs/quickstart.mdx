## Install

```bash
npm install cool-nwc
```

Node 20 or later. ESM. TypeScript declarations included. No native build step,
no postinstall scripts, no network calls at install or at runtime.

For the `cool` command as well:

```bash
npm install -g cool-nwc
```

## Record and verify

```ts
import { CooL, verifyEvidence } from "cool-nwc";

const cool = new CooL({ applicationId: "my-app" });

const { evidence } = await cool.record({
  type: "model.execution",
  metadata: { model: "my-model", version: "1.0.0" },
  // optional — commit to sensitive data without storing it
  payloads: { input: "the request", output: "the response" },
});

const verdict = await verifyEvidence(evidence);
console.log(verdict.ok);                       // true
console.log(verdict.checks.signature.status);  // "pass"
```

`new CooL()` does no I/O. The first `record()` connects the evidence plane.
With no `attestation.provider` it runs the **built-in simulator** — the same
code path, clearly labelled `simulated` in every receipt, and never `pass` on a
hardware-dependent domain.

Metadata and every `payloads` value are committed as salted hashes and
discarded: the receipt carries no plaintext.

## Try to break it

```bash
cool seal prompt billing/agent#system "Approve refunds up to $500."
cool verify last
```

Now edit one character inside the receipt file in `.cool/receipts/` and run
`cool verify last` again: `binding` and `signature` both fail, and the command
exits non-zero.
