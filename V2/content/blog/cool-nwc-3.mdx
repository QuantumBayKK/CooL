cool-nwc 3.0.0 was published to npm on 11 September 2026. The headline change is the shape of the API: most
applications need to record evidence and verify it, and the default entry point
now says exactly that.

```ts
import { CooL, verifyEvidence } from "cool-nwc";

const cool = new CooL({ applicationId: "my-app" });
const { evidence } = await cool.record({ type: "model.execution" });
const verdict = await verifyEvidence(evidence);
```

## Where everything else went

| Import | Contents |
| --- | --- |
| `cool-nwc` | `CooL`, `verifyEvidence`, `formatVerdict`, typed errors, crypto primitives |
| `cool-nwc/verify` | the standalone verifier only |
| `cool-nwc/phala` | `CoolTee`, dstack clients, quote / anchor / witness / policy / disclosure |
| `cool-nwc/node` | filesystem-backed log, unix-socket transport |
| `cool-nwc/tee` | everything, in one import |

## Unchanged on purpose

- No network calls of its own and no telemetry.
- No native build step and no postinstall scripts.
- Five runtime dependencies.
- The simulator still labels every receipt `simulated`, and the verifier still
  never reports a simulated domain as `pass`.
