# cool-tee

An alias for [`cool-nwc`](https://www.npmjs.com/package/cool-nwc) — the CooL
confidential-evidence SDK. Both names install the same library and both put the
`cool` command on your PATH.

```sh
npm install cool-nwc          # preferred
npm install cool-tee   # this package — identical, one hop
```

Documentation: <https://northwindcipher.com/sdk>
