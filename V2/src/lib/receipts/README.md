# Receipt fixtures

`index.ts` lists the fixtures the `/verify` page and the homepage verdict
terminal load. The files themselves live in `public/cool-vectors/` and are the
published `cool.receipt.v1` conformance vectors:

- generated by `cool-sdk/scripts/generate-vectors.mjs`, never edited by hand
  (`public/cool-vectors/index.json` records the expected result of each)
- sealed with the mock attestor (`runtime.mode: "mock"`), so attestation reports
  `MOCK` and anchor/witnesses report `ABSENT` in the browser — the UI says so
- verified in the browser by `src/lib/cool/verify.ts`, the real verifier; nothing
  on the page is a canned result

The tamper button calls `tamperOneByte()`: it flips one hex digit of one
committed hash in a deep copy, re-runs the verifier, and renders whatever the
verifier returns. `tests/film-verdict.test.ts` pins that behaviour.

Hardware receipts (Intel TDX on Phala Cloud) are not bundled here; their
evidence is published in the cool-sdk repository's
`artifacts/closure-verification-matrix.md`.
